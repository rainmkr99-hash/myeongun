# 오늘의 명운 (myeongun)

로그인 없이 기기 안에서 계산하는 사주 운세 PWA. 주소: https://rainmkr99-hash.github.io/myeongun/ (bit.ly/myungun)

## 변경 이력

- **v1.6.1 (2026-10-25)** — 원리 자세히 보기에 일진 원점수와 월운 맥락 가산분을 따로 표시.
- **v1.6.0 (2026-10-25)** — 일운 정밀화: 일진 천간과 원국 천간의 합·충, 천극지충, 복음, 반합, 월덕·천덕·문창귀인, 일진 천간 뿌리 세기, 급소 지도 연속 희기(중화 명식 동점 해소), 지지 위치별 가중, 월운 맥락(약하게) 반영. 일운 탭에 "오늘의 핵심 · 세 문장"(구성·신호·한 수) 신설, 분야 문장 소재 다양화(천간·지지 십성 선택 + 십이운성 절), 총운 도입·장면 라이브러리 확충.
- **v1.5.0** — PWA 배포본(카톡 인앱 탈출, 설치 안내, 총사주 4축).
