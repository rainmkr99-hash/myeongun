# 오늘의 명운 (myeongun)

로그인 없이 기기 안에서 계산하는 사주 운세 PWA. 주소: https://rainmkr99-hash.github.io/myeongun/ (bit.ly/myungun)

## 변경 이력

- **v1.11.0 (2026-10-25)** — 대운·원국 반영 보정: 대운 기둥을 원국에 대해 세운과 같은 규칙(오행 희기·합충형·삼합·복음·신살·조후·격국)으로 평가한 점수를 년운에 0.35 가산(기존에는 대운의 오행 희기만 ±0.5 반영) — 대운은 10년의 바탕. 교운기(대운 교체 전해·당해)는 두 대운 점수의 평균. 유년 궁 가중: 만 20세 미만은 일지·시지(나·배우자·자녀 궁)와의 관계·천극지충 비중을 절반으로(어린 시절의 운은 부모·집안 궁으로 발현). 월운·일운에는 년운 맥락을 통해 전달. 년운 원리 보기에 "세운 + 대운 맥락" 분해 표시. 실측 대조(1995~2025 판별력 AUC): 壬戌일 0.723→0.768, 癸亥일 0.641→0.686.
- **v1.10.0 (2026-10-25)** — 총사주 보강: 宮(궁위 — 년·월·일·시주를 초년·청년·중년·말년과 조상·부모·직장·배우자·자녀의 자리로 읽고, 지지 십성 + 일간 기준 십이운성으로 자리의 성격과 기세를 한 줄씩; 머리줄은 지금 나이대의 자리), 煞(원국 신살·공망 — 천을귀인·양인·백호·괴강·도화·역마·화개·문창·월덕·천덕·공망의 자리와 한 줄 뜻), 器에 없는 십성군/과다 십성군 진단(군겁쟁재·상관견관·재다신약·관살혼잡·인다신약 등)과 종격 표시, 補에 궁통보감 조후용신 글자(운에서 이 글자가 올 때 숨통이 트임).
- **v1.9.1 (2026-10-25)** — 실측 보정(사용자 체감 연도 대조, 1995~2025 구간 판별력 AUC 0.65→0.72): 충·형의 급소 완화 하한 0.7(기신을 맞아도 사건은 사건), 합의 기신-묶임 보너스 상한, 천을귀인·조후 운 보너스 1.0→0.5, 삼형 1.5→2.0, 충 월령 추가 감점, 지지 복음(월·일·시지), 양인운 감점, 격국 운(자평진전 순역용 — 파격 감점은 항상, 상신 가점은 신강 명식만), 격의 상신 합거 감점, 육합 가중 0.7/0.4, 복음을 년·월·시주 전체로 확장.
- **v1.9.0 (2026-10-25)** — 고전 원리 보강(일·월·년 공통): 궁통보감 조후용신표(일간 10 × 월지 12)로 조후법 교체, 종격(종아·종재·종살·종왕·종강) 판정과 희기 반전, 충의 종류 차등(왕지충 1.2 / 생지충 1.0 / 고지충·붕충 0.7 — 창고가 열리는 충), 탐합망충·합해충(합에 묶인 글자는 충을 덜 받음), 방합(계절국), 육합의 화기 희기, 양인충·백호충 감점, 삼합·방합의 원국 뿌리 가중(원국 2글자 1.0 / 1글자 0.7 / 0글자 0.5), 세운병림(세운=대운 간지), 대운 천간 ↔ 세운 천간 합·충, 교운기(대운 교체 ±1년), 투출(운 천간 = 원국 지지 정기 — 숨은 것이 드러남). 총사주에 종격·조후용신 표시.
- **v1.8.0 (2026-10-25)** — 월운·년운 업그레이드: 일운 정밀화 항목(천간 합·충, 천극지충, 복음, 반합, 뿌리 세기, 급소 연속값, 기둥 위치 가중)을 월운·년운에도 적용(위치 가중은 월운·세운용 별도), 월운 원점수에 년운 원점수의 1/4 가산. 월운·년운 탭에 핵심 네 줄(이달/올해 · 변수 · 한 수 · 리듬/달력) 신설 — 리듬은 반전 단서 + 일운 분포상 좋은 날·조심할 날 날짜, 달력은 좋은 달·조심할 달. 총운·분야 문장 압축과 힘 실림/조심 표시를 월·년에도 적용(기간어 자동 치환).
- **v1.7.0 (2026-10-25)** — 일운 화면 문장 압축: 핵심 3문장(오늘·변수·한 수)을 각 한 줄로, 십성·십이운성·합충 용어는 문장에서 빼고 회색 꼬리표로만 표기. 변수 문장은 체감 영향(점수)이 큰 사건 기준으로 선택하고 강도별 변형. 분야 운은 상황 한 줄 + 행동 한 줄로 압축, 분야별 힘 실림/조심/보통 표시, 소재 십성 × 순풍/역풍 2변형 + 행동 라이브러리. 총운은 도입+장면+결론 한 줄로 압축.
- **v1.6.1 (2026-10-25)** — 원리 자세히 보기에 일진 원점수와 월운 맥락 가산분을 따로 표시.
- **v1.6.0 (2026-10-25)** — 일운 정밀화: 일진 천간과 원국 천간의 합·충, 천극지충, 복음, 반합, 월덕·천덕·문창귀인, 일진 천간 뿌리 세기, 급소 지도 연속 희기(중화 명식 동점 해소), 지지 위치별 가중, 월운 맥락(약하게) 반영. 일운 탭에 "오늘의 핵심 · 세 문장"(구성·신호·한 수) 신설, 분야 문장 소재 다양화(천간·지지 십성 선택 + 십이운성 절), 총운 도입·장면 라이브러리 확충.
